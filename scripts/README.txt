SQL Query Fix Documentation
---------------------------
Suite de fichiers pour corriger une requête PostgreSQL problématique :

1. query-fix-documentation.md
   Documentation complète en français expliquant :
   - Les problèmes identifiés dans la requête originale
   - 4 solutions proposées avec leurs cas d'usage
   - Recommandations et bonnes pratiques
   
2. query-corrected.sql
   Fichier SQL exécutable avec les requêtes corrigées :
   - Requête simple (recommandée)
   - Fonction réutilisable
   - Fonction avec table de résultats
   - Bloc DO pour exécution ponctuelle
   
3. query-comparison.sql
   Comparaison détaillée montrant :
   - La requête originale avec annotations des problèmes
   - Exemples de corrections pour chaque problème
   - Solutions optimisées

Pour plus d'informations, consultez query-fix-documentation.md
